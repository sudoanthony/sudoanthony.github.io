The toolkit I actually reach for, not an encyclopedia. Each card says what the tool is for, how to install it on Windows and Linux, one command to get moving, and where it shows up in a writeup. It grows one tool at a time as the writeups do.

Find hosts, ports, and services

Recon & Scanning

nmnmapscanning

Network mapper. Discovers live hosts, open ports, and the service/version behind each one. First move on almost every network box.

WIN winget install Insecure.Nmap
LINUX sudo apt install nmap
CMD nmap -p- -sVC TARGET
seen in Biohazard, Abducted

Sit between the app and its backend

Web & Proxies

bpBurp Suiteproxy

Intercepting HTTP(S) proxy. Pause, read, and tamper with requests (Intercept), replay them (Repeater), and decode data. The Community edition is free.

WIN / LINUX installer from portswigger.net (bundled Java)
USE point the device/browser proxy at 127.0.0.1:8080, then install Burp's CA
seen in AllSafe
mpmitmproxyproxy

A free, scriptable intercepting proxy driven from the terminal (or a web UI). Handy when you want to automate or filter traffic instead of clicking.

WIN / LINUX pip install mitmproxy
CMD mitmproxy  or  mitmweb

Read the app without running it

Mobile: Static

jdxjadxdecompiler

Decompiles .dex bytecode back to readable Java (and much of Kotlin). Your default for reading an Android app's logic. Does not repackage.

WIN download the release zip, run jadx-gui.bat
LINUX sudo apt install jadx
CMD jadx -d out app.apk
seen in AllSafe · concept: jadx vs apktool
apkapktooldecode / rebuild

Decodes the binary manifest and resources into files, disassembles code to smali, and (unlike jadx) can rebuild the APK. Reach for it to read the manifest as text or to patch and repackage.

WIN jar + wrapper from apktool.org
LINUX sudo apt install apktool
CMD apktool d app.apk -o out
seen in AllSafe · concept: jadx vs apktool
mobMobSFautomated

Mobile Security Framework. One-shot automated static analysis of an APK/IPA: manifest flags, secrets, trackers, and a score. A triage first pass, not the whole test.

DOCKER docker run -it --rm -p 8000:8000 opensecurity/mobile-security-framework-mobsf
HOSTED mobsf.live (public/lab apps only, never a client binary)
seen in AllSafe

Talk to the device and hook the running app

Mobile: Device & Runtime

asAndroid Studioemulator

Ships the Android emulator and SDK. Create a Pixel virtual device on a Google APIs image (not Google Play) so you can get root.

WIN / LINUX installer from developer.android.com
USE Device Manager, new Pixel AVD, Google APIs image
seen in AllSafe · concept: the sandbox
adbadbdevice bridge

Android Debug Bridge. The command line that talks to a device or emulator: install apps, pull files, read logs, fire intents. The tool you live in.

WIN Android SDK platform-tools (with Android Studio)
LINUX sudo apt install android-tools-adb
CMD adb devices · adb pull · adb logcat
seen in AllSafe · concept: adb
friFridainstrumentation

Runtime instrumentation. Injects into a running app and hooks functions: read arguments, change return values, dump decrypted data, bypass root and pinning checks.

WIN / LINUX pip install frida-tools + matching frida-server on device
CMD frida-ps -U
seen in AllSafe · concept: Frida
objobjectionfrida toolkit

A Frida-powered toolkit with ready-made commands, so you can hook common things (pinning, root checks, storage) without writing scripts on day one.

WIN / LINUX pip install objection
CMD objection -g PACKAGE explore
seen in AllSafe

The primary target for this guide. An intentionally vulnerable Android app (Info Sec Adventures) with self-contained challenges across most mobile bug classes, from hardcoded secrets to certificate pinning.

INSTALL APK from github.com/t0thkr1s/allsafe releases, then adb install allsafe.apk
PKG infosecadventures.allsafe

An intentionally vulnerable Android app (Kotlin) with 20+ challenges. Used here for its working certificate-pinning screens to practice objection and Frida bypasses.

PKG owasp.sat.agoat

BACKEND Python 2 Flask in AndroLabServer/: python2 app.py (serves :8888)

The everyday helpers

Utilities

wslWSLlinux on windows

Windows Subsystem for Linux. A lightweight Linux shell inside Windows, no full VM. Used here to run the InsecureBankv2 Python 2 backend (Ubuntu 22.04 still ships python2).

WIN wsl --install in an admin PowerShell, then reboot
CMD wsl -d Ubuntu-22.04
seen in AllSafe
ccCyberChefencoding / crypto

A browser "swiss-army knife" for data: chain Base64/32/58 decodes, XOR, ROT, hex, and classical ciphers with a live preview. Fastest way to unwind an encoding stack.

HOSTED gchq.github.io/CyberChef
OFFLINE download the release and open the HTML locally
seen in Biohazard
